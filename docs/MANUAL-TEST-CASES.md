## Section A：主辦人（Host）— 22 案例

### A-1（Z）零活動首次登入

**前置**：測試 Google 帳號從未在系統建過主辦帳號。

**步驟**：
1. 打開首頁 → 進入登入頁。
2. 點「以 Google 登入」。
3. 於 Google OAuth 畫面授權。
4. 觀察被導向後的頁面。

**預期**：
- 系統以 Google `sub` 建立新主辦帳號。
- 暱稱與 email 由 Google Profile 帶入。
- 我被導向活動列表首頁。
- 首頁顯示「還沒有活動，建立一個吧」（或類似空狀態文案）。

**對應規格**：PRD §6.1、§6.4-A、UI-H-I-01、C28 引導類。

**失敗處理**：若彈出「Google 登入發生問題」→ 檢查 `id_token` 是否過期、後端是否設定正確的 client_id。

### A-2（Z）零活動使用者取消 Google 授權

**步驟**：
1. 首頁點「以 Google 登入」。
2. 於 Google 授權畫面按「取消」。

**預期**：
- 留在登入頁。
- 顯示「登入未完成，請再試一次」。
- 未建立任何後端帳號。

**對應規格**：§6.4-A、UI-H-E-01。

### A-3（O）建立一個活動 — 選「自訂」空白模板

**步驟**：
1. 已登入為主辦。首頁點「建立活動」。
2. 輸入名稱「測試自訂活動」、日期、地點。
3. 情境模板下拉選「自訂」。
4. 點「建立活動」。

**預期**：
- 活動被建立、我為 host。
- 該活動 rules=[], itemTags=[], condTags=[]（皆為空）。
- 我被導向活動主頁，顯示「尚無款項，新增第一筆」。
- 規則頁顯示固定說明區「關於分攤餘數：...」（即使規則為空）。

**對應規格**：§11.5 K 區、L13 餘數說明、C28 引導類。

### A-4（M）建立活動 — 選「烤肉/露營模板」

**步驟**：
1. 首頁點「建立活動」。
2. 輸入名稱「中秋公司烤肉」。
3. 情境模板下拉選「烤肉/露營模板」。
4. 點「建立活動」。

**預期**：
- 活動被建立。
- 進入活動 → 檢視分攤規則頁：6 條規則已載入，內容與 SPEC-ENGINE §7.1 一致。
- itemTags 有 16 個（肉品、蔬菜、海鮮、主食、水果、甜點、酒精飲品、無酒精飲品、調味料、烤肉工具、露營工具、免洗餐具、清潔用品、場地費、設備租借費、交通費）。
- condTags 有 8 個（吃素、大人、小孩、晚到、海鮮過敏、不喝酒/開車、自行前往、需搭主辦的車）。
- **交通費規則的「其他人」列顯示為「不計入」**（L9 核心）。

**對應規格**：UI-H-S-01、§11.5、L9。

### A-7（O）記帳 — 新增一筆單細項款項

**前置**：完成 A-4，成員為烤肉四人組。

**步驟**：
1. 活動主頁 → 「新增款項」。
2. 付款人下拉選「小凱」（預設本人）。
3. 新增一筆細項：
   - 名稱：「烤肉食材」
   - 金額：`2800`
   - itemTag：「肉品」
4. 觀察分攤區的**即時預覽**。
5. 點「提交」。

**預期**：
- 步驟 4 分攤區顯示：
  - 小美（吃素）→ 0 元（「不計入」標記）
  - 佳蓉（小孩）→ 560 元
  - 小凱（rest）→ 1120 元
  - 阿豪（rest）→ 1120 元
  - Σ = 2800 ✓
- 分攤區為**唯讀**，顯示「本細項套用『肉品』分攤規則，分攤由規則決定」與「前往規則頁」入口（L14 鎖一）。
- 步驟 5 提交後回活動主頁，該款項卡顯示「烤肉食材 NT$ 2800」。

**對應規格**：F0-01、UI-H-M-02、§3.3 機制〇、L14。

### A-9（E）除零・情境 A → L22 擋存 ⭐

**前置**：完成 A-4。

**步驟**：
1. 新增款項 → 一筆細項「油錢 1200 元」、itemTag：**交通費**。
2. 當下觀察：分攤區的**即時提示**。
3. 全部四位成員的 condTags 保留原樣（**皆不含**「自行前往」也不含「需搭主辦的車」——測試前先把小凱、阿豪、佳蓉的交通條件清掉；小美原本就沒有搭車條件）。
4. 點「提交」。

**預期**：
- **步驟 2**：分攤區即時顯示「無人符合此標籤的分攤規則，請改用其他標籤，或調整規則／成員條件標籤」。

- 停留原頁、輸入內容完整保留。
- 該細項分攤區展開＋紅框。
- 頁面頂部顯示「有 1 筆細項需要調整」。
- 點頂部摘要 → 捲動至該異常細項。

**對應規格**：UI-H-E-02、L22、F2-04、SPEC §3.3 機制四。

**⭐ 修正路徑（下一步驗證）**：
- 幫阿豪貼上「需搭主辦的車」→ 阻擋解除、可提交、阿豪分擔 1200。

### A-18（M）分帳產出（settle 頁）— 四維度檢視

   - 阿豪 net = 已代墊(500+400+1100) - 應分攤 = ?
